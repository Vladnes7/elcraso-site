# El’Craso — сайт салона красоты (Троицк)

Черновик сайта салона El’Craso, Троицк, Городская ул., 12. Шесть страниц: главная, «Услуги и цены», «Мастера», «Работы», «Отзывы», «Контакты».

Живая версия: https://vladnes7.github.io/elcraso-site/

## Как устроено

Статический сайт без фреймворков. Небольшой Node-сборщик собирает HTML из данных и шаблонов.

| Файл | Что внутри |
|---|---|
| `src/data.mjs` | **Весь контент:** контакты, прайс (11 разделов, 105 позиций), мастера, 10 отзывов, список фото и какое фото к какой услуге |
| `src/pages.mjs` | Шаблоны всех 6 страниц, шапка, подвал, карточки |
| `src/site.css` | Дизайн-система: палитра, типографика, блоки, адаптив |
| `src/site.js` | Мобильное меню, появление блоков, пауза ленты отзывов, фильтр и просмотр работ |
| `scripts/build.mjs` | Сборка: фото → WebP/AVIF нужных размеров, страницы → `dist/` |
| `scripts/check.mjs` | Проверка: у каждой страницы один `h1`, есть ссылка на запись, все файлы на месте |
| `Фото для сайта/`, `Телеграм-канал/Фото/` | Реальные фото салона |

Команды:

```bash
npm install
npm run build     # собрать в dist/
npm run check     # проверить сборку
npm run serve     # открыть на http://127.0.0.1:4173
npm run deploy    # опубликовать на GitHub Pages
```

Публикация: `npm run deploy` — собирает сайт и выкладывает `dist/` в ветку `gh-pages` (из неё работает GitHub Pages). Исходники живут в ветке `main`.

## Правила, которые нельзя нарушать

1. **Только реальные фото и факты салона.** Никаких сгенерированных лиц, стоковых фото, выдуманных отзывов, мастеров, цифр и услуг. Весь текст — из прайса салона, его Яндекс Карт и постов его канала.
2. **Кнопка «Записаться» всегда ведёт на** `https://n1987394.yclients.com/`. Свою форму записи не делаем.
3. **Палитра:** Desert Rock `#A48D78`, Soft Sandstone `#CBB9A4`, Creamed Oat `#E6DAC8`, Porcelain Mist `#F4F1EA`, Feather White `#FAF9F6`; текст `#2B221C`, кнопки `#3E3128`. Тёмно-синего и тёмной темы нет. У соседних блоков разные фоны.
4. **Всё скруглено:** карточки, фото, кнопки.
5. **Шрифты:** Oranienbaum (заголовки), Cormorant Italic (акцентные слова в заголовках), Onest (текст). Лежат локально в `public/fonts/`.
6. **Без тяжёлых библиотек и scroll-анимаций** — сайт должен работать без подвисаний. Анимируем только `transform` и `opacity`, учитываем `prefers-reduced-motion`.
7. Фото не должны обрезаться так, что видна только их часть.
8. Проверять на ширине 390 px (телефон), 768, 1440 и 1920.

## Как вносить правки

- Текст, цены, мастера, отзывы, фото → `src/data.mjs`.
- Разметка блоков → `src/pages.mjs`. Стили → `src/site.css`.
- После правки: `npm run build && npm run check`, открыть `npm run serve` и посмотреть глазами.
